Dashboard KPI tile — label, big tabular value, hint, and a soft tinted icon chip. Matches the Invoicius DashboardHero stats.

```jsx
<StatCard label="Faktúry" value="128" hint="celkom v systéme" icon="pi-file" accent="sky" />
<StatCard label="Automatizácie" value="3" hint="aktívne" icon="pi-bolt" accent="amber" />
```

Accents: `sky`, `violet`, `amber`, `emerald`. Use PrimeIcons for `icon`.
